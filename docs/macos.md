# macOS

`lokiotel install` and `lokiotel uninstall` are not supported on macOS in v0.2.

Use:

```bash
lokiotel start --config ~/.config/lokiotel/config.yaml
lokiotel status
```

Default macOS paths:

- config: `~/.config/lokiotel/config.yaml`
- token: `~/.config/lokiotel/token`
- state: `~/.local/share/lokiotel/`
- status: `~/.local/share/lokiotel/status.json`
